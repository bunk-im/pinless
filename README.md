# Pinless
A Privacy-Focused Pinterest Frontend.
- No tracking
- No exposing your IP address to Pinterest
- No JavaScript
- No ads
- No hassle

## Instances
See https://instances.bunk.im or [INSTANCES.md](./INSTANCES.md)

## How to deploy
1. Install docker
2. Configure docker-compose.yml
3. Run `docker compose up -d` to build and run the container as a daemon
